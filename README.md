# Echo Trading 제품 카탈로그

최신 제품 데이터베이스를 반영한 HTML·CSS·순수 JavaScript 기반 정적 웹사이트입니다. 별도 서버나 로그인 없이 `index.html`을 열면 바로 제품 목록을 볼 수 있습니다.

## v9 회사소개 PPT 기능 (2026-10-01)

### 사용 방법

1. `index.html`을 열고 소개할 제품을 선택합니다.
2. **소개자료 / PDF · PPT**를 누릅니다. 기존 빠른 출력 범위와 제품 선택을 그대로 사용합니다.
3. 자료 제목과 고객사명을 입력하고 **PPT 제품 표시 항목**을 선택합니다. PDF의 선택 항목도 가져올 수 있습니다.
4. **회사소개 PPT 다운로드**를 누르면 편집 가능한 `.pptx` 파일을 저장합니다.

16:9 슬라이드는 표지 → 안전과 건강 → 회사소개 → 글로벌 네트워크 → 국내 협업사 → 선택 제품 → 마무리 순서입니다. 처음 5장과 마지막 1장은 고정이며, 제품 정보의 길이와 항목 수에 따라 중간 슬라이드가 자동 분할됩니다. 제품을 선택하지 않으면 회사소개 6장만 생성합니다. 전달 메모는 표지의 발표자 노트에 포함됩니다. PDF는 기존 A4 출력 방식을 유지합니다.

`examples/Echo-Trading-Introduction-Sample.pptx`는 실제 다운로드 기능으로 생성한 제품 3개 포함 예시입니다.

## 제품 수정·추가

1. `manage.html`을 엽니다.
2. 제품을 선택하거나 **새 제품 추가**를 누릅니다.
3. 정보를 수정한 뒤 **목록에 반영**을 누릅니다.
4. **웹용 데이터 다운로드**를 누릅니다.
5. 내려받은 `catalog.js`를 프로젝트의 `data/catalog.js`와 교체합니다.

관리 페이지는 서버에 직접 저장하지 않습니다. 브라우저를 닫기 전에 반드시 웹용 데이터 또는 JSON 백업을 다운로드하세요.

## Excel 일괄 반영

원본 Excel을 기준 데이터로 관리하는 것을 권장합니다. Python과 `openpyxl` 설치 후 다음 순서로 갱신할 수 있습니다.

```bash
python scripts/import_excel.py "원본엑셀의 전체경로.xlsx" --output "catalog-import.json" --review "review.json"
node scripts/build_catalog.mjs "catalog-import.json" "data/catalog.js"
```

`catalog-import.json`과 `review.json`은 GitHub에 올리지 마세요. 일괄 변환은 기존 웹 목록 전체를 교체하므로 실행 전 백업하세요.

| Excel 열 | 데이터 키 | 표시 용도 |
|---|---|---|
| 제품코드 | id | 제품 식별 코드 |
| 아이템 | name | 제품명 |
| 국내 식품분류 | catalogType | 건강기능식품 / 일반식품 / 식품첨가물 |
| 대분류 | category | 원료 카테고리 |
| 소분류 (구버전: 상세 분류) | subcategory | 소분류 |
| 지표성분 | marker | 지표성분 |
| 수치 | spec | 규격 / 함량 |
| 기능 | function | 주요 특성 |
| 효능 | efficacy | 확정된 효능 (확인·검토·미정 값 제외) |
| 사용처(Application) | application | 어플리케이션 |
| 형태 | form | 형태 및 분말 출력 범위 |
| 공정 | process | 농축·추출 등 공정 및 출력 범위 |
| 원산지 | origin | 원산지 |
| 포장 | packaging | 포장단위 |
| Stock 운용 | stock | 미정 / 운용 / 미운용 |

`제조사·매입처` 열은 변환하지 않습니다. 포장란에 포함된 업체명·가격·MOQ·운송 메모와 미확정 값도 고객 표시값에서 제거하고 점검 파일에 기록합니다.

## 2026-09-18: A4 세로 압축 인쇄

1. `소개자료 / PDF 만들기` → `전체 제품`을 선택합니다.
2. `A4 세로 · 압축 목록`을 체크합니다.
3. 전체 분량을 3장 / 4장(기본) / 5장 중 선택합니다.
4. 제품명 / 지표성분 / 효능 / 원산지 / 어플리케이션을 개별 선택합니다. 기본은 5개 모두 선택이며 최소 1개가 필요합니다.
5. 인쇄창에서 A4, 세로, 배율 100%, 브라우저 머리글·바닥글 끄기를 사용합니다. 페이지 여백은 CSS에서 6mm로 지정합니다.

385개 제품은 기본 4장에 97 / 97 / 97 / 94개로 배치합니다. 3장은 129 / 129 / 127개, 5장은 각 77개입니다. 행 내용은 생략하지 않으며 실제 행 높이를 측정해 모든 페이지에 들어가는 공통 글자 크기로 조정합니다. 압축량이 많아 글자가 작을 때는 5장을 선택하거나 출력 항목 수를 줄이세요. 웹의 제품 데이터는 변경하지 않습니다. 가로형은 기존 10개/페이지 구성을 유지합니다.

업로드 시 index.html, assets/print.js, assets/print.css를 함께 교체하세요. 캐시가 남아 있으면 Ctrl+F5로 새로고침합니다.

## 2026-09-18 수정: 세로형 페이지 넘침 방지

사용자가 출력한 PDF에서 5장 설정이 6장으로 늘어나고, 자동 축소 없이 7pt로 인쇄되는 문제를 확인했습니다.

- 인쇄 전에 별도 고정 측정 영역에서 표 전체의 자연 높이를 측정합니다.
- 인쇄 시 미리보기의 조정된 글자 크기를 그대로 복사합니다.
- beforeprint가 다시 호출되어도 새 표를 생성하거나 글자 크기를 초기화하지 않습니다.
- 세로 페이지 높이를 282mm로 조정하고, 표 아래 안전 여유와 독립된 하단 안내 영역을 확보했습니다.
- 측정에 실패하면 인쇄를 중단하고 안내합니다.

검증: 385개 제품의 3/4/5장 논리 분배, 인쇄 이벤트 재호출 시 측정 결과 보존, 항목 선택 및 가로형 전환을 테스트했습니다. 실행 환경의 브라우저 접근 제한으로 수정본의 실제 Chromium PDF 렌더링은 검증하지 못했습니다.

## 출력 순번 No. 추가
