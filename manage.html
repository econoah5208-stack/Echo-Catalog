고객 화면 열기 (새 창)

제품 데이터 편집

이 화면은 브라우저 안에서만 동작하는 내부용 편집 도구입니다.
  • 로그인·권한 확인 기능이 없습니다. 웹사이트에 함께 게시되면 주소를 아는 사람은 이 화면을 열 수 있습니다.
  • 수정 내용은 서버나 웹사이트에 자동 저장되지 않습니다. 「웹용 데이터 다운로드」로 받은 catalog.js를 data/catalog.js와 교체해야 반영됩니다.
  • 새로고침하거나 창을 닫으면 내려받지 않은 수정 내용은 사라집니다. 작업 중간에 JSON 백업을 받아 두세요.
  • 원본 데이터는 Excel 제품마스터입니다. 여기서 고친 내용은 Excel에도 같이 반영해 주세요.

현재 웹사이트의 data/catalog.js를 자동으로 불러옵니다. 제품 선택 → 내용 수정 → 목록에 반영 → 웹용 데이터 다운로드 순서로 작업하세요.

제품을 선택해 주세요. 브라우저를 닫기 전에 데이터 파일을 다운로드하세요.

주요 특성·효능에는 확정된 정보만 입력하세요. 여러 적용 분야는 세미콜론(;)으로 구분합니다. 일반식품은 하위 분류에서 기능성부원료를 선택할 수 있습니다. 대분류는 기존 32개 명칭 중에서 고르면 원료 분야 메뉴에 자동으로 연결됩니다. 지표성분과 규격 / 함량은 별도 항목입니다.
